**RIZZGOD AI** is an elite, hyper-confident AI-powered texting strategist and wingman web application. It analyzes screenshots of DMs, Instagram stories, or text messages, decodes female subtext, spots hidden openings, handles defense mechanisms (like *"I have a boyfriend"* or dry energy), and crafts bold, high-tension replies that push interactions forward to dates.

🌐 **Live Website & Mobile App**: [https://rizzgod-ai-navy.vercel.app](https://rizzgod-ai-navy.vercel.app)

---

## ⚡ What This Website & App Does

### 1. 📷 Screenshot & DM Vision Scanner
- Upload or drag-and-drop DM screenshots from Instagram, Tinder, Hinge, Snapchat, or iMessage.
- Interactive **Visual Matrix Scanning** overlay with text extraction & context selectors.

### 2. 👁️ Vibe Check & Subtext Decoder
- Classifies energy into *Shit-Test / Defense Mechanism*, *Dry Energy*, *Playful Banter*, *Story Hook*, or *High Attraction*.
- Provides a plain-English explanation of what she **actually means** behind her words, along with **The Hidden Opening**.

### 3. 🔥 3-Tiered High-Tension Reply Generator
Enforces 3 battle-tested reply options:
- **THE TEASER**: Light banter to hook her or call her bluff.
- **THE BOLD CALL-OUT**: Directly turning tests and dry energy upside down without apologizing.
- **THE HIGH-TENSION DROP**: Bold, confident sexual/flirty escalation with maximum frame control.
- Includes **One-Click Copy**, **Audio Delivery Coach** (Speech synthesis to hear cadence & tone), and **Practice Arena Transfer**.

### 4. 👑 Dedicated Story Reply Studio
- Specialized flirty hooks for Instagram & Snapchat stories (Outfits, Gym selfies, Vacation/Beach, Nightlife drinks, 1 AM Moody music).
- Zero generic emojis (😍/🔥) — replaces them with bold, high-tension lines.

### 5. 🎮 Interactive Practice Arena
- Live chat roleplay simulator against realistic AI Girl Personas (*Chloe - The Boyfriend Tester*, *Maya - Sassy Hard-to-Get*, *Jessica - Dry Texter*, *Sophia - IG Story Queen*).
- **Real-Time Tension Gauge (0-100%)** and **AI Wingman Frame Ratings** (*S Rank*, *Weak Frame*, *Over-Invested*).

### 6. 🏆 Master Playbook & Emergency Vault (35+ Lines)
- 7 Master Categories covering *"I Have A Boyfriend"*, *Dry Texts*, *Story Hooks*, *"Are You A Player?"*, *Date Escalation*, *Ghost Revival*, and *Flake Recovery*.
- Live keyword search bar and audio tone playback.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18, Vite
- **Styling**: Modern Vanilla CSS, Glassmorphism, Dark Void Obsidian Theme, HSL Custom Tokens
- **AI Engine**: Google Gemini 1.5/2.0 Vision Multimodal API + Built-In High-Tension Neural Strategy
- **PWA**: Native Service Worker (`sw.js`), Web App Manifest (`manifest.json`), Safe Area Viewport Fit

## 🚀 Local Development Setup

```bash
# Clone the repository

# Navigate to folder
cd rizzgod-ai

# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
